# Code of conduct

nDimensions.AI and CharanTheAiGuy expect respectful collaboration around this
project. Discuss ideas and code constructively. Harassment, threats,
discriminatory abuse, and publication of another person's private information
are unacceptable.

Report concerns privately to the maintainers through an existing direct project
channel. The maintainers may remove abusive content or restrict participation
to protect contributors. Reports should be handled with appropriate discretion.
