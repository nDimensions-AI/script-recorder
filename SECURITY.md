# Security

Security reports for nDimensions.AI Script Recorder should be sent privately to
nDimensions.AI or CharanTheAiGuy through an existing direct project channel.
A dedicated security address has not yet been designated.

Do not post vulnerabilities, credentials, or sensitive recordings in public
issues. Include affected versions, reproduction steps, potential impact, and a
minimal example with confidential information removed. The maintainers will
coordinate investigation and remediation; no response deadline is promised.

For a vulnerability in a third-party component, follow that component's own
reporting policy and notify this project's maintainers privately when relevant.
